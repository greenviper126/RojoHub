# Group projects

A group is a named set of projects, like a profile. Groups are listed in the **Groups** dropdown of the Rojo-Hub sidebar, below Projects.

1. Click **+** on the **Groups** header in the sidebar and name the group. A dropdown opens for its first project.
2. To add more, click **+** on the group's row. Each click opens a dropdown of the projects not in the group yet.
3. To take a project out, click **✕** on its row inside the group.

Then:

- **Start Group** serves every project in the group.
- **Serve Only This Group** serves the group and stops every other project.
- **Stop Group** stops the group's projects.

Projects that are already serving are left alone, so their Studio connections stay. A project can be in several groups.
