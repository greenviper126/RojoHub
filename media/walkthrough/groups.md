# Group projects

A group is a named set of projects, like a profile. A project can be in several groups.

- **Start Group** serves every project in the group.
- **Serve Only This Group** serves the group and stops every other project.
- **Stop Group** stops the group's projects.

Projects that are already serving are left alone, so their Studio connections stay. A group remembers which projects it holds, not their branches; each project keeps whatever branch you last switched it to.
