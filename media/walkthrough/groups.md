# Group projects

A group is a named set of projects, like a profile. Groups have their own section in the Rojo-Hub panel, below Projects.

1. Click **+** on **Groups**, type a name and press Enter.
2. In the group's card, pick a project from **Add a project…**. Repeat for each project you want in it.
3. To take a project out, click the **✕** next to it.

Then, on the group's card:

- **Start** serves every project in the group.
- **Only this** serves the group and stops every other project.
- **Stop** stops the group's projects.

Projects that are already serving are left alone, so their Studio connections stay. A project can be in several groups.
