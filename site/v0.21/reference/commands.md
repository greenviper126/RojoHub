# Commands

Everything is in the panel. For the keyboard, the command palette has:

| Command | Does |
|---|---|
| **Rojo-Hub: Open Menu** | The panel's actions as quick picks: projects, groups, Add Project, New Group, settings, Stop All. |
| **Rojo-Hub: Copy Agent Setup Commands** | The `claude` / `codex` setup commands and a JSON entry for other agents. |
| **Rojo-Hub: Copy Agent Setup Prompt** | A paragraph to paste into any agent so it sets itself up. |

The status bar shows `Rojo :<port> · <branch>` in a window on a registered project; click it to open
the project's card.
